# SA Motion Studio v12 — Remotion · HyperFrames · دمج

## الجديد
| الميزة | الوصف |
|---|---|
| **اختيار المحرك** | Remotion / HyperFrames / دمج من بطاقة «محرك الرندر». المحرك غير الجاهز يُعطَّل ويُكتب سببه الحقيقي. |
| **HyperFrames** | تركيبة HTML حتمية تُرندر إطاراً بإطار (Chromium + ffmpeg) **بعدة عمّال متوازية** (تلقائياً حسب المعالج، أو `SA_HF_WORKERS`). |
| **معاينة حية** | زر «معاينة حية» يشغّل التصميم داخل الموقع مع شريط تمرير، بدون رندر، بنفس التوقيتات والكلمات. |
| **الدمج** | **طبقات** (HyperFrames خلفية + Remotion شفاف فوقها أو العكس + شفافية) أو **تتابع** (كل مقطع زمني بمحرك). إن فشل جزء Remotion يُسلَّم الباقي مع تحذير بدل ضياع كل شيء. |
| **السكربت ← فيديو** | قواعد ثابتة (بدون ذكاء اصطناعي): مقدمة · سؤال · **مقارنة** · **دورة** · خطوات · رقم · مفهوم · نقاط · خلاصة. |
| **ثيمات** | علمي داكن · نيون · ورقي فاتح · ذهبي فاخر. |
| **محاذاة دقيقة** | كل جملة من السكربت تُطابَق على كلمات التفريغ فتبدأ مشاهدها لحظة نطقها (تتحمل أخطاء التفريغ). |
| **حفظ المشروع** | `.samotion.json` يحفظ المحرك والأكواد والسكربت والتفريغ والتوقيتات. |
| **مجلد الخطوط** | ضع خطوطك في `fonts/` فتُستخدم تلقائياً. |
| **أفقي وعمودي** | التصميم يتكيّف مع 9:16 و16:9 و1:1. |

**لم يتغيّر:** الصوت، التفريغ، المزامنة، المؤثرات، الموسيقى، الحسابات والاشتراكات، الرندر السحابي لـ Remotion.

## الأمان والثبات
- صفحة HyperFrames تُرندر في متصفح **معزول الشبكة**: يُسمح فقط بالخادم المحلي وخطوط/مكتبات (Google Fonts, cdnjs, jsDelivr)، وأي طلب لعنوان داخلي يُحجب (حماية SSRF). المعاينة الحية داخل iframe بـ `sandbox`.
- مهلة لكل إطار (90ث): حلقة لا نهائية تُنهي المهمة برسالة واضحة بدل التعليق.
- الإلغاء ينظّف كل العمليات (متصفح + ffmpeg).
- التثبيت يضيف `playwright-core` (خفيف، بلا متصفح إضافي) ويستخدم متصفح Remotion الموجود.

## كتابة HyperFrames
```html
<div id="root" style="position:absolute;width:1080px;height:1920px">…</div>
<script>
window.drawFrame = (t, SA) => {          // كل شيء دالة في الزمن t فقط
  SA.fit(document.getElementById('root'), 1080, 1920);
  const p = SA.p(t, 0.5, 1.2, 'expo');   // تقدّم 0..1
  box.style.opacity = p;
};
</script>
```
متاح: `SA.props.words/segments/scenes` · `SA.p` · `SA.pop` · `SA.ease` · `SA.rand(seed)`. ويدعم `data-start/data-duration/data-track-index` و`window.__timelines` (GSAP إن ثبّتّه).
ممنوع: `Math.random` و`setTimeout` و`requestAnimationFrame`. الوسائط: `<video src="current_video.mp4" data-start="0">`.

## نتائج الفحص الفعلي (عبر التطبيق الحقيقي)
- ✅ الرندر الكامل بدءاً من السكربت: HyperFrames، لقطات، تعليق صوتي (بمولّد وهمي) مع تمديد المدة ومزج الصوت.
- ✅ التوازي يعطي نفس الإطارات تماماً (فُحصت بصمة كل إطار) · ✅ مزامنة الكلمة لحظة نطقها.
- ✅ حجب SSRF (خدمة داخلية لم تتلقَّ أي طلب) · ✅ مهلة الحلقة اللانهائية · ✅ الإلغاء بلا عمليات يتيمة.
- ✅ الطبقات الشفافة والتركيب والتتابع · ✅ سقوط Remotion إلى HyperFrames مع تحذير.
- ✅ الواجهة والمعاينة الحية في متصفح حقيقي.

## ما لا يمكنني ضمانه من بيئتي
- رندر **Remotion** الفعلي (alpha/frameRange): لا يوجد Remotion هنا. جرّب «دمج ← طبقات» مرة؛ وإن فشل ستحصل على HyperFrames مع تحذير يشرح السبب.
- TTS وWhisper الحقيقيان (لم أمسّهما).
- مقطع اليوتيوب وحزمة HyperFrames الرسمية: لم أصل إليهما؛ المحرك هنا تنفيذ داخلي بنفس تسمية الخصائص.
- السرعة: أجهزتي معالج واحد؛ على معالج متعدد النوى ستتضاعف تقريباً بعدد العمّال.
